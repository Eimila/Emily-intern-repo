# API List App

This SwiftUI macOS app fetches items from the JSONPlaceholder API and displays
them in a SwiftUI `List`.

## What It Shows

- `List` rendering API items.
- `Codable` decoding.
- `async/await` networking.
- loading, error, empty, and refresh states.

## Run

From the repository root:

```bash
swift run --package-path APIListApp
```

You can also open the `APIListApp` folder in Xcode and run the package.
