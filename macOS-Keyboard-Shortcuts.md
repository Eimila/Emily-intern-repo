# macOS Keyboard Shortcuts

This note lists 20 useful macOS keyboard shortcuts, including the key combination and what each shortcut does.

## Shortcut List

1. **Command + C** — Copy the selected item or text.
2. **Command + V** — Paste the copied item or text.
3. **Command + X** — Cut selected text or supported editable content.
4. **Command + Z** — Undo the previous action.
5. **Command + Shift + Z** — Redo the previously undone action.
6. **Command + A** — Select all items or text in the current window or document.
7. **Command + S** — Save the current document or file.
8. **Command + P** — Open the print dialog.
9. **Command + F** — Find text or items in the current app.
10. **Command + Tab** — Switch to the next recently used app.
11. **Command + Space** — Open Spotlight search.
12. **Command + Q** — Quit the active app.
13. **Command + W** — Close the active window or tab.
14. **Command + N** — Open a new window or document.
15. **Command + T** — Open a new tab in supported apps.
16. **Command + M** — Minimize the active window.
17. **Command + Option + Esc** — Open the Force Quit Applications window.
18. **Command + Shift + 3** — Take a screenshot of the entire screen.
19. **Command + Shift + 4** — Select an area of the screen to screenshot.
20. **Command + Shift + .** — Show or hide hidden files in Finder.

## Reflection

These shortcuts support common macOS workflows such as editing text, managing windows, switching apps, searching, taking screenshots, and working with Finder.
