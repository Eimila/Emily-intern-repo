# Protocol Default Implementation Playground

Open `ProtocolDefaultImplementation.playground` in Xcode, then run the
playground.

This playground demonstrates:

- A protocol named `ReportPrintable`.
- A required method named `printSummary()`.
- A default implementation provided in `extension ReportPrintable`.
- A conforming type that uses the default implementation.
- A conforming type that overrides the default implementation.
